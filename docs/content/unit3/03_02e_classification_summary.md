# Lesson summary

**In this lesson you have learnt about kNN as an example of a lazy classifier. kNN, albeit simple, can be a quite powerful technique, especially for large datasets.**

Nevertheless, it suffers from serious limitations when the data is not suitably pre-processed, including rescaling of data to avoid dominance of one attribute over others. With lazy classifiers we don’t have a learning stage. During the deduction process the algorithm therefore needs to scan the entire dataset in order to come up with an answer. This is why it is not suitable for real time application. kNN also constitutes our first fully numerical classification method. In the next couple of units, we will look extensively at numerical classification methods that go beyond kNN capabilities, and beyond using distance metrics only.
